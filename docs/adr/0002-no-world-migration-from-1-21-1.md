# The 26.1 line does not migrate 1.21.1 worlds

Researchd on 26.1 makes no promise to load research progress, team data, Research Lab contents or stored energy saved by the 1.21.1 line. Worlds start fresh. This frees the port to change save formats as it moves to NeoForge's value I/O and transfer APIs, without migration code or migration test fixtures. Any future request for world upgrades is a new decision, not a regression.
